# Project Assets

프로젝트별 공개 자산을 관리하는 폴더입니다.

```text
projects/
├─ yogiyo/
│  ├─ images/
│  └─ documents/
├─ patrol-robot/
│  ├─ images/
│  └─ documents/
└─ uni/
   ├─ images/
   └─ documents/
```

이미지는 소문자 영문과 하이픈으로 이름을 짓고, UI 캡처는 PNG, 실제 사진은 JPG 또는 WebP를 사용합니다. 문서와 이미지의 개인정보를 검토한 뒤 프로젝트 데이터에 연결합니다.
